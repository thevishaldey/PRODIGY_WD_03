PRODIGY_WD_03

Task 3 : Tic-Tac-Toe with Ai mode 

This project is one of the many intern projects for Web Development Internship at Prodigy InfoTech. In this, we were supposed to make a browser-based Tic-Tac-Toe game built with plain HTML, CSS and JavaScript. Two players can take turns on the same screen, or one player can face a computer opponent. The game includes a light/dark theme switch, animated moves, and optional spoken commentary from the computer. 
It runs entirely in the browser. There is no build step, no backend and nothing to install.
_________________________________________________________________________________________________________________________________________________________________________
✨ Features
- Two game modes
- Win and draw detection
- Dark mode
- Voice commentary
- Move animation
- Colour-coded players
- Status messages
- Restart button
- Responsive layout
__________________________________________________________________________________________________________________________________________________________________________
🛠️ Technologies Used
- HTML5 :	Page structure and the game board.
- CSS3	: Custom animation, transitions and winning-cell colours.
- Tailwind CSS (via CDN)	: Layout, colours, spacing and dark mode styling .
- JavaScript : (vanilla, no frameworks)	Game logic, AI opponent, theme toggle and events.
- Web Speech API (speechSynthesis)L: Spoken AI commentary.
- Google Fonts (Inter)	Typography.
